CodeCrew 1.0 is out.

CodeCrew is Radius Red's lightweight framework for agent-driven software delivery: a gh CLI extension, four role contracts, and a set of conventions on plain GitHub — no server, no dashboard, no new place to look. Milestones are issues, tasks are issues with a plan in them, decisions are comments in a fixed shape, and the gates are enforced by a CLI that refuses rather than reminds.

Project home: https://github.com/radiusred/gh-codecrew

Version 1.0 means a stable CLI and a versioned protocol: verbs and refusal codes keep their meaning within a major release. Since we introduced it a week ago, all four seats in our own crew are held by GitHub App identities, merges are agent-gated — a reviewer App's approval satisfies GitHub's own required-review rule — and the record's own plumbing was found wanting, and fixed.

What changed since the introduction, and how to start, in the 1.0 article: https://www.radiusred.uk/blog/posts/2026-08-27-codecrew-1-0-the-crew-is-staffed-and-the-gates-have-teeth/

## Tags — how they were chosen (2026-08-27)

The operator asked for independent research rather than instinct (PR #50).

**Bluesky.** Discovery is keyed on tags (custom feeds and search match
them), so volume is what matters. Measured with the authenticated
`app.bsky.feed.searchPosts` endpoint: hours needed for a tag to accumulate
its latest 100 posts (smaller = busier).

| tag | hours / 100 posts | | tag | hours / 100 posts |
|---|---:|---|---|---:|
| #AI | 1 | | #AIAgents | 32 |
| #Tech | 3 | | #DevTools | 76 |
| #OpenSource | 10 | | #AgenticAI | 82 |
| #LLM | 14 | | #GitHub | 82 |
| #Programming | 18 | | #SoftwareEngineering | 93 |
| #Coding | 24 | | #AIEngineering | 789 |
| #DevOps | 25 | | #SoftwareDelivery | dead (89 posts ever) |

Chosen: `#AI` (the broad anchor, noisy but where the feeds are),
`#OpenSource` (busy and exactly on topic), `#Programming`, `#AIAgents`
(the relevant niche), `#DevOps`. Dropped: `#CodeCrew` (no community yet;
the name is in the text and searchable), `#DevTools`, `#SoftwareDelivery`.

**LinkedIn.** LinkedIn removed hashtag *following* in late 2024; tags are
topic signals for its distribution algorithm. Every 2026 guide consulted
agrees on 3–5 tags per post and a broad + mid + niche mix; published
follower counts disagree by source but rank consistently:
`#ArtificialIntelligence` 3–11M, `#SoftwareEngineering` ~4M, `#DevOps`
200K–890K, `#AIAgents` ~320K. Chosen: `#ArtificialIntelligence`,
`#SoftwareEngineering` (broad), `#OpenSource`, `#DevOps` (mid),
`#AIAgents` (niche). Dropped: `#CodeCrew`, `#DevTools`, `#SoftwareDelivery`.
Sources: Sprout Social, Writio, SocialRails, Vaizle, Pollen (LinkedIn
hashtag guides, 2026).
