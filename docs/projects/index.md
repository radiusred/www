# Projects

Technical documentation for Radius Red's open-source projects. Each project's docs are synced from the upstream repository on every build.

Radius Red curates the open-source tooling that comes out of its engineering work, past and future. `tradedesk` and its companion tools were built for our first venture, a systematic F/X trading operation that has since wound down — they remain open source and available. As new ventures start, their open-source output will be added to this list too. `gh-codecrew` is the framework our own agent crew runs on — this site is one of its spokes.
